## 2. 用例清单

### 2.1 生命周期（CONTRACT）

- P2-LC-001 合法链路 proposed→draft→validating→pending_approval→approved→published。
- P2-LC-002 跳级 draft→approved 拒绝。
- P2-LC-003 validation_failed→draft 允许；→approved 拒绝。
- P2-LC-004 rejected 不能直接 published。
- P2-LC-005 published→deprecated→archived。
- P2-LC-006 每次转换写 skill_event 与 AuditLog。
- P2-LC-007 非法状态枚举拒绝。

### 2.2 提议（PROP）

- P2-PROP-001 单次任务不产生提议。
- P2-PROP-002 3 次同类成功任务产生 1 条提议。
- P2-PROP-003 成功率 < 0.8 不提议。
- P2-PROP-004 相似任务签名合并，不重复提议。
- P2-PROP-005 已有同签名 Skill → 不提议或标记 duplicate。
- P2-PROP-006 跨 Project 不合并。
- P2-PROP-007 来源 task/memory 完整保留。
- P2-PROP-008 提议数上限（默认 20）生效。
- P2-PROP-009 无成功来源不提议。
- P2-PROP-010 名称不同但签名相同仍去重。

### 2.3 草稿（DRAFT）

- P2-DRAFT-001 合法提议生成结构化草稿。
- P2-DRAFT-002 缺失 inputs/outputs 拒绝。
- P2-DRAFT-003 未知工具拒绝。
- P2-DRAFT-004 未授权工具拒绝。
- P2-DRAFT-005 `executionMode` 非 declarative 拒绝。
- P2-DRAFT-006 含 code/eval 字段拒绝。
- P2-DRAFT-007 基于旧版本时 diff 字段完整。
- P2-DRAFT-008 草稿不覆盖正式 Skill。
- P2-DRAFT-009 来源字段完整。
- P2-DRAFT-010 权限扩大被标记 incompatible。

### 2.4 验证（VAL）

- P2-VAL-001 Schema 失败 → FAIL。
- P2-VAL-002 静态安全失败（eval）→ FAIL。
- P2-VAL-003 功能 fixture 通过。
- P2-VAL-004 输出契约不符 → FAIL。
- P2-VAL-005 无回归案例 → CONDITIONAL_PASS。
- P2-VAL-006 安全用例跨 Profile → FAIL。
- P2-VAL-007 超时 → 稳定性 FAIL。
- P2-VAL-008 阻断项存在不得进入 pending_approval。
- P2-VAL-009 验证不写正式库。
- P2-VAL-010 Evaluation 不改变安全结论。

### 2.5 审批发布（APPR）

- P2-APPR-001 未审批 publish 拒绝。
- P2-APPR-002 Agent approve 拒绝。
- P2-APPR-003 无 publish 能力拒绝。
- P2-APPR-004 已拒绝版本不能发布。
- P2-APPR-005 安全 FAIL 不能发布。
- P2-APPR-006 contentHash 变化导致审批失效。
- P2-APPR-007 权限扩大需重新审批。
- P2-APPR-008 重复发布幂等。
- P2-APPR-009 发布保留旧版本。
- P2-APPR-010 发布写 Publication + AuditLog。

### 2.6 版本与回滚（VER）

- P2-VER-001 正常升级指针切换。
- P2-VER-002 同版本号冲突拒绝。
- P2-VER-003 MAJOR 变更需重新审批。
- P2-VER-004 回滚到既有 published 版本。
- P2-VER-005 回滚不删除新版本。
- P2-VER-006 回滚不改历史 execution。
- P2-VER-007 目标版本有已知漏洞拒绝。
- P2-VER-008 多次回滚各自留痕。
- P2-VER-009 并发发布单指针。
- P2-VER-010 compareVersions 输出正确。

### 2.7 作用域（SCOPE）

- P2-SCOPE-001 Profile A/B 隔离。
- P2-SCOPE-002 Project A/B 隔离。
- P2-SCOPE-003 Agent 不在 allowedAgents → 拒绝。
- P2-SCOPE-004 Tool 未授权 → 执行前拒绝。
- P2-SCOPE-005 复制 Skill 不复制权限。
- P2-SCOPE-006 导入 Skill 不授予权限。
- P2-SCOPE-007 项目级提升为 Profile 级需新版本+审批。
- P2-SCOPE-008 全局共享不存在。

### 2.8 使用与反馈（USE）

- P2-USE-001 成功执行记录 executionId/taskId/traceId。
- P2-USE-002 失败分类正确。
- P2-USE-003 重试不重复计成功。
- P2-USE-004 成功率口径：任务级。
- P2-USE-005 超时/取消单独统计。
- P2-USE-006 反馈写入与脱敏。
- P2-USE-007 改进建议生成 proposal，不直接改版本。
- P2-USE-008 使用记录跨版本对比可用。
- P2-USE-009 执行不保存敏感正文。
- P2-USE-010 递归成长上限生效。

## 4. 性能与稳定性

- Store 单次读写 < 50ms（Node 内存后端基准）。
- 提议扫描 100 条任务 < 1s。
- 验证 20 个用例 < 5s（fixture，无网络）。
- 连续 100 次执行记录写入无泄漏（内存/IDB 基本检查）。
- 超时、取消、重试各 1 条用例覆盖。
