# ASTRUM 太阳系观测视图 · 实现方案说明

版本 1.1 · 2026-10-23（已实施）
适用项目：`astrum/`（纯静态、零依赖、可直接双击 `index.html` 运行）
本文件先行给出方案，再据此实施；技术栈、渲染方案、代码风格与 UI 规范全部沿用现有工程。

---

## 〇、与现有工程的关系（先定边界）

现有工程的技术底座是：

| 现有能力 | 位置 | 本次如何复用 |
| --- | --- | --- |
| Canvas 2D 渲染 | `core/app.js` 的 `drawSky` / `drawGlobe` / `miniMoon` | 太阳系视图同样用 Canvas 2D，不引入 WebGL/three.js |
| 透视相机基向量 | `drawSky` 内的 `fwd / right / upv` | 升级为通用 3D 相机（yaw/pitch/roll + 透视投影） |
| JPL 近似轨道根数 | `core/astro.js` 的 `PL` 表与 `helio()` | 直接复用，太阳系视图的行星位置与 2D 星图**同源同刻** |
| 天体资料 | `data/bodies.js` 的 `BODY_INFO` | 扩展为完整太阳系数据（半径/质量/自转/卫星/纹理参数） |
| 信息卡与悬停提示 | `#viewerInfo` / `.obj-info` / `.sky-tip` | 复用 DOM 与 CSS 规范，做成太阳系视图的信息面板 |
| 全屏浮层 | `#viewer` / `.viewer` | 复用浮层骨架与头部/底部工具条布局 |
| 深链与面板协作 | `#viewer=1` / `#target=xx` | 新增 `#solar=1` / `#solar=土星` |
| 智能体编排 | `core/agents.js` | 新增「领航」智能体与 `system-view` 意图 |

**关键约束**：项目承诺「零依赖、可离线、双击即用」。因此：

- 不使用 three.js / Babylon / WebGL 上下文，不引入任何 CDN 脚本或外部字体。
- 不加载外部位图贴图（会破坏离线承诺，且需引入跨域与体积问题）。**贴图改为程序化生成**：以 NASA/JPL 公开的**实测特征参数**（反照率、纬向带位置、大红斑尺寸与纬度、极冠范围、卡西尼缝半径、自转周期、轴倾角、云层速度）为输入，实时烘焙等距圆柱投影贴图，再按法线做逐像素光照合成。效果目标是「有真实表面特征与明暗」而非卡通色球。

## 一、天体数据来源与字段结构

### 1.1 数据来源

| 字段 | 来源 | 备注 |
| --- | --- | --- |
| 半径、质量 | NASA Planetary Fact Sheet（2023 版） | 行星/矮行星与卫星分表 |
| 自转周期、轴倾角 | 同上（Sidereal Rotation & Axial Tilt） | 负值表示逆行自转 |
| 反照率（几何） | NASA Fact Sheet | 用于程序化贴图的基础亮度 |
| 轨道半长轴/偏心率/倾角/升交点/近日点幅角 | `core/astro.js` 的 JPL 近似根数（1800–2050） | **不重复造轮子**，直接复用 |
| 轨道位置 | `Astro.helio(key, jd)` | 日心黄道坐标 (x, y, z)，单位 AU |
| 卫星轨道与半径 | NASA Fact Sheet 卫星表 + 各任务公开值 | 共 17 颗主要卫星 |
| 表面特征参数 | 任务公开结论（朱诺号、卡西尼、MESSENGER、Akatsuki、Hubble 等） | 用于纹理生成，见 §2.1 |
| 纹理色板 | 各任务公开影像的代表性色 | 作为程序化贴图的目标色 |

### 1.2 字段结构

```js
// data/solarsystem.js
root.SOLAR = {
  au: 149597870.7,          // 1 AU = km
  bodies: [
    {
      key: 'saturn', cn: '土星', en: 'Saturn',
      kind: 'planet',          // star | planet | moon
      parent: 'sun',           // 母天体
      radiusKm: 58232,
      massKg: 5.6834e26,
      rotationH: 10.656,       // 自转周期（小时，负为逆行）
      axialTilt: 26.73,        // 轴倾角（度）
      albedo: 0.499,
      color: '#e3d0a4',
      glow: '#bda678',
      tempC: '云顶约 −139 ℃',
      atmosphere: null,        // 大气辉光参数
      rings: { innerKm: 74500, outerKm: 140220, divisions: [...] },
      texture: 'saturn',       // 贴图生成器标识
      moons: ['mimas', 'enceladus', ...],
      missions: [...], sources: [...]
    }
  ],
  moons: [ { key:'enceladus', cn:'土卫二', parent:'saturn', radiusKm:252.1, ... } ]
};
```

**字段纪律**：半径与质量一律用国际单位（km、kg），距离用 AU 参与计算并在显示层转成 km；所有数值随应用发布即固定并标注来源与核验年份，不随运行时刻变化（只有位置、角度、可见性随时间变化）。

## 二、贴图与光照 / 阴影策略

### 2.1 程序化等距圆柱贴图（每个天体烘焙一次，缓存）

以 512 × 256 的 `ImageData` 烘焙，参数全部来自实测：

| 天体 | 贴图生成规则（依据实测特征） |
| --- | --- |
| 太阳 | 米粒组织（多频噪声）+ 临边昏暗（limb darkening 由 1.0 → 0.6）+ 谱斑暗区 |
| 水星 | 灰色基岩 + 多尺度陨击坑（环形山密度按月面统计）+ 卡洛里盆地同心山环 |
| 金星 | 硫酸云顶：沿经向拉伸的涡旋条带（超旋转，周期约 4 天），色带 2.1% 反照率 |
| 地球 | 海洋（深蓝，反照率 0.06）+ 大陆块（按真实经纬范围绘制的主要陆块）+ 极冠冰盖 + 独立云层（自转更快的第二贴图） |
| 月球 | 灰色 + 月海暗斑（按真实月海经纬绘制）+ 辐射纹 |
| 火星 | 氧化铁锈色（反照率 0.17）+ 暗反照率区（Syrtis 类）+ 南北极冠（水冰/干冰，随季节消长）+ 水手谷与奥林帕斯山 |
| 木星 | 纬向带纹（按真实 Zone/Belt 纬度）+ 大红斑（南纬 22°，长轴约 1.3 万 km）+ 极区多边形气旋 + 白色椭圆 |
| 土星 | 淡金色弱带纹 + 北极六边形 + 极区涡旋 |
| 天王星 | 青蓝（甲烷吸收红光）+ 极淡带纹 + 亮云斑 |
| 海王星 | 深蓝 + 带纹 + 大暗斑（旅行者 2 号 1989 观测形态） |
| 卫星 | 灰阶岩质 + 撞击坑密度（按各卫星表面年龄差异调整） |

噪声使用**确定性伪随机**（固定种子），保证每次启动纹理一致、无闪烁。

### 2.2 球面合成（逐像素法线 + Lambert）

对每个可见像素：
1. 由像素偏移求球面法线 `n`（球面坐标 `lon = atan2(nx, ny) + 自转相位`，`lat = asin(nz)`）。
2. 采样等距圆柱贴图（双线性可选，先用最近邻 + 轻微抖动去色带）。
3. 计算光照：`diff = max(0, dot(n, L))`，`L` 为太阳方向转换到天体本地坐标系（含轴倾角）后的单位向量。
4. 合成：`color = albedo * (ambient + diff * (1 - 0.55*rim^2))`，临边昏暗与大气散射按各自规则叠加。
5. 写入 `ImageData` 并 `putImageData` 到离屏画布。

### 2.3 阴影与特殊效果

| 效果 | 做法 |
| --- | --- |
| 球体明暗界 | Lambert + 软化项 `smoothstep(-0.12, 0.22, dot)`，避免锯齿状明暗界 |
| 大气辉光 | 球体外再画一圈加性径向渐变（地球蓝、金星橙黄、泰坦橙） |
| 地球云层 | 第二张独立贴图，旋转相位略快，透明度 0.85 叠加在表面之上 |
| 环系（土星/天王星） | 由内径/外径与卡西尼缝等分界生成环形贴图，投影为椭圆环面；受行星遮挡（前后半环分别绘制） |
| 环上行星投影 | 环面按太阳方向做一条投影暗带 |
| 日冕与耀斑 | 太阳表面之外叠加加性径向渐变 + 3 条程序化耀斑弧（沿磁区缓慢摆动），每帧重绘（成本低） |
| 行星本影 | 木星等卫星在行星圆面上按太阳方向投下椭圆暗斑（按卫星位置与半径计算） |
| 行星凌星 | 从相机方向看，卫星在行星前时按遮挡关系绘制 |

### 2.4 性能策略（LOD 与缓存）

| 层级 | 触发条件 | 渲染方式 |
| --- | --- | --- |
| L3 精细 | 屏幕半径 ≥ 40 px | 逐像素合成球面贴图，缓存为离屏 sprite |
| L2 中等 | 12 ≤ r < 40 px | 解析式带纹 + 明暗渐变（不再逐像素），按 2° 相位量化缓存 |
| L1 简化 | 3 ≤ r < 12 px | 单色盘 + 径向明暗 + 一圈光晕 |
| L0 隐去 | r < 3 px | 仅绘制 1.5 px 光点（保留可点性） |

缓存策略：

- 等距圆柱贴图：**每天体烘焙一次**，常驻内存（512×256×4B ≈ 512 KB/张 → 约 20 张 ≈ 10 MB；卫星贴图降为 256×128）。
- 球面 sprite：按 `(天体, 半径档位, 自转相位量化, 光照档位)` 作为键缓存；自转相位量化步长随半径自适应（r≥40 时 0.5°，否则 2°/5°），保证太阳系视图最多每 100 ms 重建一次大球体。
- 轨道线：每行星预生成 256 段折线（黄道面），只在视距/目标变化时重投影。
- 对象池：轨道折线、标签矩形、命中体列表复用同一批数组，主循环内零分配。
- 剔除：背面天体与屏幕外天体跳过；被太阳遮挡的天体降低亮度（可选「轨道标签显隐」联动）。
- 帧预算：`requestAnimationFrame` + delta 时间，步进上限 50 ms（防止切后台回来后跳跃）；页面不可见时暂停。

## 三、尺寸与距离的缩放映射公式

### 3.1 三个缩放层级

| 层级 | 相机距离 | 目标 | 用途 |
| --- | --- | --- | --- |
| `system` 全系视图 | 42 AU | 太阳 | 太阳系全局结构与行星排布 |
| `planet` 近景行星视图 | 0.002 – 0.6 AU | 选中行星 | 行星 + 内侧卫星 + 环系 |
| `close` 天体特写 | 3 – 12 倍天体半径 | 选中天体 | 表面细节、环系、晨昏线 |

切换层级时相机沿视线平滑插值（600 ms，ease-in-out），不跳变。

### 3.2 投影公式

世界单位：**1 AU = 1 单位**。相机在目标点后 `D` 个单位，fov = 45°。

```
k      = (H/2) / tan(fov/2)                     // 焦距（像素）
v      = R(yaw, pitch) · (P − T)                // 相机空间坐标
screen = (cx + v.x/v.z · k,  cy − v.y/v.z · k)  // 透视投影
depth  = v.z                                   // 用于排序与遮挡
```

### 3.3 天体尺寸映射

真实半径换算：`r_AU = radiusKm / 149597870.7`

```
r_px = r_AU × k / v.z × boost
```

- `boost` 为**统一缩放系数**（所有天体共用），保证天体之间的**直径比例始终等于真实比例**（木星 11.2 倍地球、太阳 109 倍地球），只是整体放大或缩小。
- 默认 `boost = 1`（真实比例）。全系视图下地球约 1 px、木星约 11 px、太阳约 107 px——这正是真实比例的视觉结果；界面提供 `boost` 滑杆（1×–200×）与「真实比例」一键复位。
- 界面始终显示当前生效的两个比例因子（距离比例 px/AU、尺寸比例 px/km）与「相对真实比例的放大倍数」，避免用户误判。

### 3.4 轨道半径映射

```
r_orbit_AU = a(1 − e²) / (1 + e·cos ν)          // 椭圆轨道真近点角 → 半径
```
位置直接复用 `Astro.helio()`，不做二次近似。

### 3.5 自转与公转

- 公转：模拟时间 `t = t0 + elapsed × timeScale`（默认 `timeScale = 86400`，即 1 秒 = 1 天），代入 `Astro.helio()`，**公转周期天然与真实周期一致**（含开普勒偏心率）。
- 自转：相位 `φ = φ0 + 2π · Δt / (rotationH/24)`，逆行天体（rotationH < 0）自然反向。
- 时间档位：`实时 / 1 天每秒 / 10 天每秒 / 1 年每秒`，可暂停与倒放。
- 帧率：位置每帧更新（仅 8 次开普勒迭代，开销可忽略）；只有贴图 sprite 需要重建，受 §2.4 缓存节流。

## 四、轨道标签与相机控制方案

### 4.1 标签

- 默认显示：天体名 + 当前日心距离（AU）。
- 可选叠加：日心距（km）、视直径、光照相位、视星等。
- 排版沿用 `drawSky` 的避让算法（`placed[]` 矩形占用表 + 越界夹取），先画太阳与选中天体，其余按屏幕重要性排序。
- 标签层级：选中 > 行星 > 卫星；远处重叠时只保留重要者。

### 4.2 相机控制

| 操作 | 行为 |
| --- | --- |
| 拖拽 | 绕目标旋转（yaw / pitch），pitch 夹在 ±89° |
| 滚轮 | 沿视线推拉（D 按 1.12 倍步进，夹在 [0.00005, 120] AU） |
| 单击天体 | 选中并高亮（描边 + 光晕 + 标记环），信息面板同步 |
| 双击天体 | 切到 `planet` 层级并锁定该天体为相机目标 |
| 滚轮 + Shift | 调整 `boost`（天体统一缩放） |
| 1 / 2 / 3 | 切换全系 / 近景 / 特写层级 |
| Tab / Shift+Tab | 在天体间循环选中（可访问性） |
| 方向键 | 微调相机角度；+/- 缩放；R 重置；L 切换标签；H 隐藏 UI |
| Esc | 关闭太阳系视图 |

### 4.3 选中反馈

- **描边**：外扩 2 px 的亮色描边（选中色 #e8c894）。
- **光晕**：径向加性渐变。
- **标记环**：与轨道平面平行的椭圆环（近景层级下垂直于视线）。
- **标签**：加粗并常驻。
- 命中检测：屏幕空间圆形命中，优先级按屏幕半径降序（避免大球体遮挡小卫星）。

## 五、Agent / 交互流程统一（实施第 3 步）

### 5.1 新增意图与智能体

- 新增内置智能体 **Navigator（领航）**：负责视图操作类指令。
- 新增意图 `system-view`：解析「打开太阳系」「聚焦土星」「全系视图」「隐藏轨道」「放大天体」「重置视角」等。

### 5.2 任务类型与统一输出格式

| 任务类型 | 触发示例 | 处理链路 | 输出格式 |
| --- | --- | --- | --- |
| 查询天体数据 | 「土星的质量是多少」 | 命中数据表 → 返回结构化字段 | `system` 段：字段表 + 与当前观测状态合并 |
| 切换视角 | 「聚焦木星」 | 解析目标 → 校验存在 → 下发相机指令 | `system` 段：已执行动作 + 结果状态 + 层级 |
| 调整显示设置 | 「隐藏轨道标签」 | 解析设置项 → 校验范围 → 应用 | `system` 段：设置项 + 新值 + 生效范围 |
| 异常输入 | 「聚焦天狼星」「打开火星」 | 实体校验失败 → 给出最近候选 | `boundary` 段：不可执行原因 + 候选列表 |

统一「结构化响应」章节类型 `system`，字段固定为：`action / target / state / fields / next`，保证工具调用稳定、可追溯。

### 5.3 推理步骤呈现

所有分支共用同一套协作链路渲染（`renderTrace`），新增 Navigator 节点后，链路顺序调整为：
`Muse → Vega/Navigator → … → Curator → Critic`。异常输入必须走完 Critic（证据复核），确保「已声明无法执行」这一结论本身也被核验。

## 六、UI 走查与细节打磨（实施第 4 步）

- **布局层级**：顶栏（标题/来源/设置）→ 视图头部（层级切换、标签开关、缩放、时间档位）→ 画布 → 底部天体导航条 → 左侧信息面板（可折叠）。
- **视觉一致性**：沿用 Daylight Paper 变量（`--paper/--ink/--accent`），浮层用深色（与现有全屏星图一致），信息面板用 `.obj-info` 既有规范。
- **响应式**：≥1120px 面板常驻左；860–1120px 面板改为可折叠浮层；<860px 面板转为底部抽屉，天体导航条横向滚动。
- **可访问性**：
  - 键盘可完成「选中 → 换层级 → 调标签 → 关闭」全流程；焦点可见（沿用 `:focus-visible`）。
  - 画布提供 `role="img"` 与 `aria-label` 描述当前场景；天体列表提供 `role="listbox"`/`option` 语义，屏幕阅读器可读出选中项。
  - 对比度：深色浮层文字与背景对比度 ≥ 4.5:1（复测 `--ink` 在 `#0e131d` 上的实际对比度）。
  - 加载与错误态：首帧计算期间显示占位与进度；WebGL/Canvas 不可用时给出降级说明。

## 七、安全加固（实施第 5 步）

| 面向 | 措施 | 落点 |
| --- | --- | --- |
| 输入校验 | 提问长度上限 200 字；天体名白名单校验（只接受数据表内 key）；所有动态文本经 `esc()` 转义 | `core/app.js` |

### 9.2 偏离一：距离布局默认「压缩」而非严格等比

真实等比（`r ∝ a`）下，海王星轨道半径是地球的 30 倍、水星只有 0.39 倍，若再要求天体按真实直径绘制，地球在屏幕上只有 0.0004 像素——整个内行星区会退化成几个不可见的点。

因此实现为**双模式**：

| 模式 | 映射 | 说明 |
| --- | --- | --- |
| 压缩布局（默认） | `r = 30·(a/30)^0.5` | 内行星可分辨，整体结构清楚；页脚实时标注公式 |
| 真实等比（一键切换） | `r = a`（AU 严格线性） | 满足「按真实天文距离比例排布」的严格定义；顶部「真实等比」按钮一键切换 |

页脚始终显示当前生效的映射公式与放大系数，不隐藏任何偏离。

### 9.3 偏离二：太阳按固定屏幕尺寸绘制

太阳直径是地球的 109 倍。在任何「跨 30 AU 全景」的布局里，只要让太阳保持严格比例，它的视直径就会覆盖整个内行星区。因此太阳改为**固定屏幕半径**（`min(W,H)×3.2%`，10–46 px 之间），配合程序化日冕、耀斑与临边昏暗表达「强光源」；其真实半径 695,700 km 始终显示在信息面板中，页脚也明确标注了这一处理。

除太阳外，**八大行星与 21 颗卫星之间的直径比例严格等于真实比例**，只用一个全局统一放大系数 `boost` 整体缩放：

| 层级 | 默认 boost | 原因 |
| --- | --- | --- |
| 全系 | ×5,000 | 让木星、土星等在全景中可见 |
| 近景 | ×40 | 兼顾卫星与母星的空间关系（木卫二仍能绕木星运行） |
| 特写 | ×1 | 真实比例，专注表面细节 |

`boost` 可用顶部滑杆在 ×1 – ×20,000 之间连续调节（对数映射），滑杆只改变整体大小，不改变任何天体之间的比例。

### 9.4 验收结果
