# ASTRUM-07 产品功能边界

## 1. 产品定位（审计判断）
ASTRUM 是**本地优先、离线可用、可选云端模型的天文学习与观测辅助工作台**，同时内置一套「任务/证据/Skill」的 Agent 工程演示。它不是专业星历软件、不是多用户平台、不是自主科研系统。

## 2. 明确可用（A/B 级）
| 能力 | 说明 | 依赖 |
|---|---|---|
| 离线知识问答（20 问） | 本地知识库 + 规则/模板回答 | 无 |
| 星图 | 9096 颗 BSC5 亮星、DSO、星座示意、银河背景 | 无 |
| 太阳系 3D / 行星近景 | 程序化纹理、相位、光照 | 无 |
| 观测计划 / 天气 / 地理位置 | 本地数据 + 可选 open-meteo | 可选网络 |
| 计算器 / 天文换算 | 本地 | 无 |
| 检索取证问答 | 多源检索 + 证据 ID + 引用核验 | 网络 |
| 报告生成 | 本地 | 无 |
| 附件（PDF/FITS/图片） | 本地解析 | 无 |
| 项目 / 记忆 / 导入导出 | IndexedDB | 无 |
| Skill 提案→发布→执行 | 本地 | 无 |
| 任务暂停/恢复 | 刷新后手动恢复 | 无 |

## 3. 有条件可用（C 级）
| 能力 | 条件 | 降级行为 |
|---|---|---|
| 云端模型回答 | 用户自备 API Key | 无 Key 时明确提示并本地作答 |
| 实时检索 | 网络可达 | 失败时本地索引兜底并标注降级 |
| PubMed/arXiv/SIMBAD 等 | 网络可达 | 失败标 pending/降级 |
| 浏览器兼容 | 现代 Chrome/Edge | 其他浏览器未验证 |

## 4. 不具备（E/F 级）
1. **后台常驻执行**：关闭页面即停止；P4 是「中断后可恢复」。
2. **真正的多智能体自主协商**：无 Agent 间消息传递/动态分工。
3. **精密星历**：月球/行星为近似模型；恒星未做岁差。
4. **自主观测控制**：不连接望远镜、不执行拍摄。
5. **多用户安全隔离/协作**：无认证、无服务端权限。
6. **自动科学发现**：不提出假设、不设计实验。

## 5. 模拟/演示属性（必须声明）
- 行星表面纹理：程序化生成，非 NASA 实测影像。
- 随机星场/银河：视觉素材；银河来自 NASA SVS 公有领域，非测量星表。
- 星座连线：示意 stick figure，非 IAU 官方边界。
- 「Agent 人格」：角色化文案，不是独立智能体。

## 6. 对外表述风险
| 现有表述 | 风险 | 建议 |
|---|---|---|
| 「天文多智能体工作台」 | 暗示自主协作 | 改为「多角色 Agent Pipeline」 |
| 「精密/高精度」相关措辞（如有） | 与实际模型不符 | 标注近似模型与适用时段 |
| P4「恢复」 | 易被理解为后台续跑 | UI/文档写明「刷新后手动恢复」 |

## 7. 适用与不适用场景
**适用**：天文入门学习、课堂演示、观测前粗查、个人观测记录、Agent 工程参考。
**不适用**：专业定轨/精密指向、科研论文数据、多人共享账号、无人值守长任务、安全敏感环境。

## 8. 结论
产品**边界清晰、降级诚实**，主要风险是**营销表述超出实现**。只要在 README/关于页明确「非精密星历、非自主多智能体、非后台执行」，即可安全面向公众。
