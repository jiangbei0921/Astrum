### 4. 安全清单
**已证实的防护：**
1. 单一授权入口 `Security.authorize`，校验 principal 完整性、会话一致性、ownerProfileId/projectId、能力白名单。
2. `ToolGateway` 显式拒绝 `profileId/projectId/principal/sessionId/ownerProfileId` 参数，并有参数 Schema 校验。
3. TaskStore 按档案分库（`Profile.ns`）+ `ownerProfileId` 过滤；恢复前重新授权并重新校验 Skill 版本。
4. Skill 仅执行 `published` 版本，校验档案、Agent 白名单、所需能力/工具；静态禁止动态代码与越权字段。
5. CSP 存在且较严格：`default-src 'self'`、`object-src 'none'`、`frame-ancestors 'none'`、仅两个内联脚本 hash 放行。
6. 未发现 `eval` / `new Function`；未发现未转义的用户/模型内容直入 `innerHTML` 的可利用路径。
7. 隐私声明与实现一致：默认无服务器、无埋点、无第三方脚本；API Key 明文 localStorage 已在隐私页披露。

**已证实/潜在风险：**
- 本地档案切换无认证，属于「数据分区」而非安全边界（P2）。
- `style-src 'unsafe-inline'`、`connect-src` 含 localhost、Key 明文、CORS Worker 路径与大小限制不足、AuditLog 可篡改（均 P3）。

### 5. 天文结论
- 时间与坐标基座正确：GMST 与 Meeus 例 12.a 偏差 < 0.0005 h；月球与 Meeus 例 47.a 偏差在 0.03° 内；太阳春分赤纬偏差 < 0.05°；地球近日/远日点距离偏差 < 0.0007 AU；Alt/Az 方位约定为「北起、向东为正」，边界与极区无 NaN。
- **P1 问题**：星表为 J2000（且未施加自行），却直接与「当日恒星时/当日黄赤交角」混合，未做岁差改正。2026 年恒星位置系统性偏移约 **0.36°**；太阳/行星反而是 of-date。银河纹理沿用同一逆变换，方向一致但同样带偏移。
- 月球为 Meeus 截断项、行星为 JPL 近似根数，属合理近似；**未获取外部星历逐日对照，行星精度标「待验证」**。
- 银河背景来自 NASA SVS（公有领域），行星表面为**程序化生成**，不是实测影像。

### 6. 功能边界
- 可用：离线知识问答、20 问、星图/太阳系/行星近景、观测计划、计算器、检索取证、报告、PDF/FITS 附件、项目/记忆、Skill 生命周期、任务暂停/恢复。
- 受限：云端回答依赖用户自备 Key；无 Key 时明确降级为本地表述。
- 不具备：后台常驻执行、真正的多 Agent 自主协商、精密星历/自主观测控制、服务端多用户隔离、协作与权限管理。
