## 1. 测试分层与入口

| 层 | 入口 | 依赖 | 是否离线 |
|---|---|---|---|
| 单元（纯模型） | `node tools/p1-project-test.js`、`p1-memory-test.js` | 无 DOM/IndexedDB | ✅ |
| 集成（存储） | `node tools/p1-store-test.js` | 内存/LS 回退适配器 | ✅ |
| 权限/隔离 | `node tools/p1-security-test.js` | `Security` + mock Profile | ✅ |
| 召回 | `node tools/p1-context-test.js` | 内存记忆集 | ✅ |
| 恢复/检查点 | `node tools/p1-resume-test.js` | TaskStore 内存后端 | ✅ |
| 导入导出 | `node tools/p1-import-export-test.js` | 内存存储 | ✅ |
| 浏览器 | `tools/p1-browser-test.js`（可选，需 Chrome） | 真实 IndexedDB | ❌ 需授权 |

所有新增测试沿用现有风格：独立 Node 脚本、自带断言、末尾输出 `RESULT n/n`。
