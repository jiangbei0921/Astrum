## 1. 当前数据与链路

生产视觉表 `data/sky-stars-l1.js` 含 9,096 条 HEASARC BSC5P 记录，记录为7字节/星，文件大小179,821字节（约175.6 KiB）。`core/sky-star-data.js` 解码为 `Float32Array` 赤经度/赤纬/视星等/B-V及光谱代码；统计：B-V缺失310，谱型代码缺失1，视星等范围约 -1.45 至 7.96。元数据显示位置历元J2000且未施加自行。源记录HR及完整光谱型尚未存在于当前生产数据，所以对全体记录调用 `recordAt()` 时 `sourceId/hr/spectType` 仍为null；旧名称表仅覆盖带名称亮星。

主要链路：`data/sky-stars-l1.js` → `core/sky-star-data.js` → `SkyVM.model()` 计算L1 alt/az缓存 → `SkyVM.build()`投影并构造 `vm.field` → `SkyRenderer.fieldStars()`按亮度/颜色分桶绘制；`CAT.stars`仍作为L0业务实体，独立的L1字段另维护部分带名恒星点击兼容。

## 3. 数据许可审计

现有决策文档和生成数据将本版本标为NASA HEASARC修订版BSC5P、美国政府作品（公有领域），并保留官方数据.gov记录与USA.gov政府作品信息链接。该决定限于当前注册/分发的HEASARC版本，不扩展成Yale原始星表的笼统授权。Gaia/Hipparcos/Tycho等候选此前许可有非商业限制风险，本轮未将其导入；官方ESA许可页面抓取未返回内容，故本轮不重新宣称已重新核证这些候选。当前生产数据可继续沿用，不需要替换。
