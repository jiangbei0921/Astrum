## 4. 当前 UI 能力分析

### 4.1 可直接完成

- 日期、时刻（分钟粒度）任意设置：`#ctxDate`、`#ctxTime`
- 任意经纬度 + 任意 UTC 偏移：`#btnManualCoord` → `#coordLat` / `#coordLon` / `#coordTz`
- 视场角 50/70/100/140/170 近似取值：全屏滚轮 / `#vwIn` / `#vwOut`，读数 `#vwVal`
- 方向环顾：全屏拖动（yaw 任意，pitch −5°–72°）
- 复位与目标定位：`#vwReset`、`#bodyRail`、`#catList`
- 标注密度：`#viewerLabels`

### 4.3 新增的是产品能力，不是测试专用 UI

本阶段未建独立测试页面（会绕过或放宽 `index.html` 的 CSP，存在污染正式环境的风险）。新增的三处属于**正式产品能力**，验收与日常使用共用：

1. 全屏星图视场角快捷档位（6 档）；
2. 设置 → 显示 → 星图图层（7 个开关 + 持久化）；
3. 设置 → 数据与档案 → 数据来源补 BSC5P / NASA SVS 署名与恒星颜色说明。

另提供只读控制台观测片段（方案 §7.1/§7.2），只调用已公开接口，不改文件、不改参数、不改 Canvas。

## 6. 实机验收需要用户执行的内容

1. 打开项目：双击 `D:\Projects\Astrum\index.html`（或按方案 §2.2 用本地 HTTP / 重新构建 standalone）。
2. 点「观测台」→ 确认日期 `2026-06-01`、时刻 `21:30`、地点 `39.9042, 116.4074, UTC+8`。
3. 点「全屏查看星图」进入 `#viewer`。
4. 按方案 §4 顺序执行 A → D/E → B → C → F → G。
5. 每个测试项填写 `docs/V2-SKY-阶段3A-测试记录模板.md` 对应表格。
6. 截图按 `3A-类别-FOV-地点-日期-序号.png` 命名，存入 `docs/3A-shots/`（目录不存在请自行创建）。
7. 发现异常时在 `docs/V2-SKY-阶段3A-问题清单.md` 登记（含复现条件与截图）。
8. 回传：最终结论（PASS / CONDITIONAL PASS / FAIL）+ 未测项 + 问题清单。
