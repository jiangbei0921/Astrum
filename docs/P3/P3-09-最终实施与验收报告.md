## 2. 行为说明与兼容性

1. **schemaVersion 不变**：新增字段全部可选；`create()` 白名单与 `makeStep()` 已同步，`fromJSON` 可加载旧任务。
2. **旧任务预算兼容**：缺失 `recoveries` 时按档位补齐，最低允许 1 次恢复，避免历史任务永久不可恢复。
3. **goal 默认不改变旧链路**：仅 `goalEnabled: true` 时创建 goal；UI 经 `AstroRequest` 默认开启，Node 直调 `Control` 的既有路径保持不变。
4. **暂停语义**：写入 `pausedAt` 与 `task.paused`；`runPlan` 在新批次前返回 `PAUSED`，不声称中断在飞请求。`resume` 清除 `pausedAt` 并计入恢复预算。
5. **恢复门槛**：最新检查点缺少 `stateHash` → `CHECKPOINT_INVALID`；次数耗尽 → `RECOVERY_LIMIT`。对无检查点的旧任务保持兼容。
6. **结果复用**：`ok` 且输入哈希未变才复用；输入变化则重置为 `pending` 重跑。未强制重跑所有非幂等步骤，避免破坏既有恢复测试。
7. **并行副作用**：同批不混合两个写共享证据步骤；输出合成与 Skill 步骤串行；非幂等工具不并行。
8. **DAG 校验定位**：作为纯函数模块与调度前的并行过滤使用；未把 `validate()` 硬接入 Planner 的失败路径，避免拒绝既有 T-E/T-F 模板计划（并行检索降级为串行而非拒绝）。
