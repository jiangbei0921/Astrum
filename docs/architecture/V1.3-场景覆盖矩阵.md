## 备注

- **云端复杂研究**：请求确实进入 AstroControl，使用本地 Compose；旧云模型表述未调用。科学证据链路完整，但回答风格/模型表述能力下降，故标 PARTIAL。
- **显式对比**：仅本地、无附件、forceCompare 时接管；Web 对比保留旧流程。
- **论文附件**：现有附件不是论文 PDF 解析入口；仍走旧附件流程。全文能力通过 `paper.search + fulltext` 进入，见规范。
- **混合附件与对比**：未开放，避免目标证据与附件证据混淆。
- **出版社 PDF**：部分返回 HTML/反爬，全文失败会明确记录，不伪装。
