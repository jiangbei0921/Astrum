## 分流规则（`AstroControlBridge.canControl`）

```
info.control === true
AND mode !== 'compare'
AND sourceType === 'local'
AND (attachments.length === 0 OR 全部为已解析 FITS)
```

## 已验证边界

- L1 永不进入 Control。
- Router 只执行一次；Control 使用 `routeData`。
- 附件 Evidence 不丢失；对比目标不丢失。
- 取消/失败不伪装成功。
- 控制层失败可安全回退旧链路，并保留原因。
- FITS 附件不存在时不会伪造观测。
- 论文/未知附件不进入 Control，不做假全文。

## 未覆盖场景

- 论文全文抽取（DEFERRED）。
- Web/云端复杂研究统一控制（PARTIAL，保留旧能力优先）。
- 显式对比模式 Control 接管（PARTIAL，需专用对比 compose）。
- 远端 GitHub Pages/Actions（DEFERRED，无权限）。
