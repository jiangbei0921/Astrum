# ASTRUM V1.2 科学证据规则

> 日期：2026-11-01
> 适用：Evidence / Claim / Reducer / Report。原则：可追溯、可复算、不虚构。

---

## 1. Evidence 来源独立性

| 情况 | 规则 | 结果 |
|---|---|---|
| 同 DOI 多镜像（arXiv/OpenAlex/ADS） | DOI 优先键 | 只保留 1 条，记 `duplicates` |
| 无 DOI、同标题不同 URI | 标题 + 年份 + 首作者键 | 视为同一论文，去重 |
| 不同 DOI | 独立 | 分别保留 |
| 同标题但作者/年份不同 | 不合并 | 独立研究 |
| 无 DOI、无作者、标题过短 | 不按标题合并 | 保守保留 |
| 同一数据源重复记录 | `sourceId` 相同 | 独立来源计数只算 1 |
| 文本/图片附件 | 不生成科学 Evidence | 只进 gaps |

`independentSources` 按唯一 `sourceId` 计数，不按 URL 数量。

---

## 2. Claim 类型与范围

| 类型 | 来源 | 要求 |
|---|---|---|
| 事实（fact） | 数据库/观测原始值、PASS Claim | 必须有 evidenceRefs |
| 推断（inference） | PARTIAL Claim、摘要级语义支持 | 标明证据范围 |
| 假设（hypothesis） | FAIL/无支持 Claim | 不得写成事实 |
| 定量（quantitative） | FITS/计算 | 必须有 CalcRecord；缺 uncertainty 按 R4 处理 |

- 论文只取摘要时 `abstractOnly=true`；结论 `evidenceScope='abstract-only'`。
- 不声称阅读全文；不把摘要支持标成全文强证据。
- 报告 `limitations` 明确摘要/缺失数据。

---

## 3. 单位与量纲

支持常用天文单位换算（用于冲突比较，不改变原始展示值）：

| 量纲 | 单位 |
|---|---|
| length | ly, pc, kpc, Mpc, au, km |
| angle | deg, arcmin, arcsec, mas, rad |
| temperature | K, kK |
| time | yr, kyr, Myr, Gyr |

规则：
1. 先按实体 + 量纲分组。
2. 同量纲换算到 canonical 单位后比较。
3. 不同量纲（如 ly vs K）不比较。
4. 原始 `raw` 值始终保留。

---

## 4. 冲突判定

```
同实体 + 同量纲
  ├─ 参考系/历元不同 → differences: insufficient_information
  ├─ 有不确定性：
  │    diff > sqrt(u1² + u2²) → conflicts: significant
  │    否则 → 不标记
  └─ 缺不确定性：
       relative spread > 5% → differences: insufficient_information
       否则 → 不标记
```

- `conflicts` 只放“满足条件”的显著差异。
- `differences` 放无法科学判断的差异，不伪装成冲突。
- `conflictsOf` 保持返回数组；`compareClaims/differencesOf` 提供完整结构。
- 不把测量差异自动解释成数据错误。

---

## 5. 不确定性

- FITS 统计使用 `std/sqrt(n)`，语义是**样本均值标准误**（measurement）。
- 不代表仪器误差、系统误差、模型误差或完整置信区间。
- 缺少误差数据时不生成虚假误差/置信区间。
- 报告 `uncertainties` 与 `limitations` 说明范围。

---

## 6. 报告表达

必须区分：
- 真实数据支持的结论；
- 论文摘要支持的结论；
- 观测文件支持的结论；
- 推断；
- 来源冲突；
- 缺失数据；
- 不确定性未知/不完整；
- 无法进一步验证的结果。

不隐藏缺口；不为了“完整”虚构数值或来源。
