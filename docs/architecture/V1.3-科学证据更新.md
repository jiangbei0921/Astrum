# ASTRUM V1.3 科学证据更新

> 日期：2026-11-01
> 适用：Evidence / Claim / Reducer / Report / Research UI。

---

## 1. 证据分层

| contentLevel | 含义 | abstractOnly |
|---|---|---|
| metadata | 论文元数据 | true |
| abstract | 摘要 | true |
| fulltext | 公开 PDF 正文块 | false |
| extracted_claim | 从全文提取的具体主张 | 预留，当前未自动抽取 |

- 同 DOI 摘要/全文分开存储，不互相覆盖。
- 独立来源仍按 DOI/sourceId 计 1；镜像不重复计数。
- 全文 Evidence 必须带 section/page/URL，页码未知写 null。

---

## 2. Claims

- 全文 Claim 仍以 `partial` 支持强度进入，不把作者假设当事实。
- 定量 Claim 必须有 CalcRecord；缺 uncertainty 按 R4 处理。
- 每个 Claim 必须带 `evidenceRefs`；报告不展示无来源结论。
- 摘要 Claim 不能标成 `fulltext`。

---

## 3. 冲突与差异

- 同实体 + 同量纲分组；单位换算（ly/pc、deg/arcmin/arcsec 等）。
- 有不确定性：差异 > 1σ 合成不确定性 → `conflicts.significant`。
- 缺不确定性：只记录 `differences.insufficient_information`。
- 参考系或历元不同：`differences`，不判冲突。
- 不同量纲：不比较。
- 不同目标：按实体分组，不串扰。

---

## 4. 报告

新增/保留字段：
- `paperStats`：检索数、全文数、仅摘要数、失败数、全文/摘要证据数；
- `papers[].fulltextAvailable/pageCount/sections/pageStart/pageEnd`；
- `conclusions[].evidenceScope`：abstract-only / fulltext / observation / calculated / catalog；
- `limitations`：摘要级、缺 SIMBAD、缺 FITS、差异无法判定；
- `gaps`：仅摘要、全文失败、缺失数据。

---

## 5. 不确定性

- FITS：`std/sqrt(n)` = 样本均值标准误，非完整仪器/系统误差。
- 全文：不自动生成数值 uncertainty；需要 CalcRecord 才能定量。
- 缺误差不伪造置信区间；报告标注 measurement 范围。

---

## 6. 证据独立性

- 同 DOI 多镜像 → 1 条（保留 duplicates）。
- 无 DOI 同标题 + 年份 + 首作者 → 同一论文。
- 不同 DOI → 独立。
- 同标题不同年份/作者 → 独立。
- 全文多个 chunk 不增加独立来源数量；它们是同一论文的不同位置。

---

## 7. UI 区分

- 概览：全文 x / 仅摘要 y。
- 论文条目：全文/仅摘要、页数、章节。
- 结论：`evidenceScope` 显示。
- 局限：摘要级、全文失败、缺 SIMBAD/FITS。
- 链接：仅 http(s)，`rel=noopener noreferrer`，外部文本转义。

---

## 8. 不伪造规则

- 未下载/解析成功 → 不得生成 fulltext Evidence。
- 出版社 HTML/反爬 → `not_pdf`，记录失败。
- 页码/章节不可靠 → null 或省略。
- 不从摘要推断全文结论。
- 不把同一论文的多个 chunk 计为多个独立来源。
