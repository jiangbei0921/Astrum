## 2. 评分机制

每个案例记录 10 个维度，不用单一总分掩盖严重错误：

| 维度 | 检查 |
|---|---|
| 意图理解 | route mode 是否符合 research/compare；模板是否正确 |
| 任务拆解 | T-E/T-F/T-D；是否调用 paper.search/evidence.search/compare.curate |
| 检索相关性 | 论文标题/结论是否命中主题词（仅一项维度，不是全部） |
| 来源可信度 | 标题、http(s) 链接、年份、DOI/arXiv/URI |
| 数据准确 | 本地案例的已知数值；全答案无 NaN/undefined/Infinity |
| 证据完整性 | 结论 evidenceRefs 全部落在 evidence ids 内 |
| 不确定性 | gaps/limitations/boundary 是否保留 |
| 结论质量 | verdict、必要章节、关键词/对象 |
| 多 Agent 协作 | 预期 Agent 是否参与 |
| 输出质量 | 结构、长度、无伪影 |

硬性门槛：论文不可追溯、结论引用坏链、NaN/undefined 任一出现 → 直接 FAIL。

## 7. 结论

本轮独立盲测证明：

- 未收录天体也可通过真实论文检索进入 T-E/T-F；
- 论文真实性、来源链接、年份、结论引用均可核验；
- 不确定性在证据不足时被保留；
- 多 Agent 协作未突破 ADR-001 预算；
- 没有用关键词命中替代研究过程。

局限：21 个真实网络案例依赖 OpenAlex/arXiv 可用性；本轮全部可达，不能保证未来每次网络 CI 都相同。
