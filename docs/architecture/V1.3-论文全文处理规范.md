# ASTRUM V1.3 论文全文处理规范

> 日期：2026-11-01
> 适用：`paper.search` 全文扩展、`core/paper-fulltext.js`、`core/pdf-text.js`。

---

## 1. 合法来源

允许：
- arXiv 公开 PDF（`arxiv.org/pdf/...`）。
- OpenAlex / Semantic Scholar 返回的开放获取 PDF 链接。
- 其它明确公开、无需登录/付费的 PDF。

禁止：
- 付费墙、登录、访问控制、版权保护绕过。
- 把出版社 HTML 反爬页面当作 PDF。
- 把摘要/元数据伪装成全文。
- 上传 PDF 到后端或第三方服务。

无公开全文时：保留元数据/摘要，`abstractOnly`，记录 `fullTextUnavailable` 原因。

---

## 2. 下载

| 限制 | 默认 | 说明 |
|---|---|---|
| maxBytes | 12 MB | Content-Length + 实际 arrayBuffer 双重检查 |
| timeoutMs | 30 s | AbortController |
| signal | 调用方 | Control 取消贯穿下载 |
| redirect | follow | 仅公开跳转 |
| 内容类型 | application/pdf / octet-stream | HTML 明确 `not_pdf` |

失败码：`fulltext_unavailable / not_pdf / pdf_too_large / timeout / network / cancelled`。

---

## 3. PDF 解析

`core/pdf-text.js`（零依赖）：
- 2880/80 字节结构由 PDF 对象解析器处理；
- FlateDecode 使用 `DecompressionStream('deflate')`；
- 支持对象流（ObjStm）、页面树、内容流；
- 无页面树时扫描非图像 Flate 内容流（页码写 null）；
- 文本提取：`Tj` / `TJ` / `'` / `"`，TJ 字距数字仅在较大负值插入空格；
- 章节识别：Abstract/Introduction/Results/Discussion/References/编号标题；
- 分块：按段落/句子边界，单块 ≤1400 字符；
- 页码未知时 `pageStart/pageEnd = null`，不伪造；
- 限制：40 页 / 200k 字符 / 40 块；
- 失败：`pdf_empty / pdf_too_large / not_pdf / pdf_encrypted / pdf_no_text`。

已知限制：
- 扫描件、CID 字体无 ToUnicode、复杂版面可能无法可靠提取；
- 解析是 CPU 同步过程，AbortSignal 只能在开始前检查；
- PDF 被截断时给出警告，仍可能提取部分正文。

---

## 4. 内容块字段

```
chunkId, paperId, title, section, content,
pageStart, pageEnd, doi, sourceUrl, contentType='fulltext', provenance
```

`provenance`：extractionMethod、pdfUrl、pageCount、chunkIndex、retrievedAt。

---

## 5. Evidence

`contentLevel='fulltext'`，`abstractOnly=false`，并保留：
- `paperId`、`chunkId`、`section`、`pageStart/pageEnd`、`doi`、`pdfUrl`；
- `extractionMethod`、`sourceUrl`、`pageCount`、warnings。

同 DOI 的摘要 Evidence 与全文 Evidence 分开存储（key 含 level/chunk），但独立来源仍按 DOI/sourceId 计 1。

---

## 6. Claims / Report / UI

- 全文 Claim 仍使用保守 support（partial），不把作者假设升级为已验证事实。
- Report `paperStats`：searched / fulltext / abstractOnly / failed / fulltextEvidence / abstractEvidence。
- 论文条目：`fulltextAvailable`、`pageCount`、`sections`、`pageStart/pageEnd`、`evidenceIds`。
- Report `limitations`：摘要级、缺 SIMBAD、缺 FITS、无法判定差异。
- UI：概览显示“全文 x / 仅摘要 y”；论文条目标记全文/仅摘要、页数、章节；链接 `noopener` + HTML 转义。

---

## 7. 缓存与资源释放

- 缓存 key = `paperId|url`，最多 8 篇，LRU 淘汰。
- 同一 PDF 重复请求直接复用解析结果。
- 失败结果也缓存（避免重复下载同一失败 URL）。
- 不持有全局大数组；解析完仅保留 chunks/evidence/元数据。
