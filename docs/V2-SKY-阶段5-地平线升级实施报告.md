## 2. 变更细节（`core/sky-renderer.js`）

### 2.1 `directionLabels()`

- 细刻度：`az` 每 10°，跳过 30° 倍数，`rgba(132,172,214,0.30)`，长度 `5k`；
- 主刻度：`az` 每 30°，`rgba(170,196,226,0.55)`，长度 `9k`；
- 度数：仅非四正方向（`az % 90 !== 0`）标注，避免与 N/E/S/W 叠字；
- 八向字母：颜色与位置不变（`rgba(216,226,244,0.55)`，`y + 20k`），保证阶段 1 的绘制顺序断言 L6.5 仍能定位。

### 2.2 `bodyLayer()` 与 `labels()`

- `src.below` 且 `alt > −6°`：虚线 `[5k, 2k]`、`lineWidth 1.3k`、alpha `0.72`；更深处维持 `[3k, 3k] / 0.45`；
- 天体标签前缀由 `↓ ` 改为 `↓ 已落下 `，明确「在地平线下」而非「不可见」。

### 2.3 未改动

- `Astro.altAz`、`SkyVM` 投影、`SkyLayers` 的 7 键结构、L0/L1 星表与命中、冻结视觉参数（F/G/ALPHA/纹理/采样/光晕）、B4.2 探针位置与阈值。

## 4. 已知限制

| 编号 | 限制 | 说明 |

| H-L1 | 未接入真实地形 / DEM | 山脊为固定伪随机轮廓，仅示意 |
