## 1. 缩放失效的真实根因

不是事件没绑上，而是**改错了变量**：

```js
// 修复前
function zoom(f) {
  cam.dist = clamp(cam.dist * f, 0.00002, 160);   // 只改当前距离
  ...
}
```

渲染循环每帧执行 `cam.dist += (cam.gdist - cam.dist) * 0.16`，而 `cam.gdist` 没变，
于是下一帧立刻把 `cam.dist` 拉回原值 —— **滚轮、双指捏合、键盘方向键全部被静默抵消**。

```js
// 修复后
function zoom(f) {
  cam.gdist = clamp(cam.gdist * f, 0.00002, 160); // 改目标距离，交给缓动动画
  ...
}
```

### 配套改动

| 项 | 内容 |
|---|---|
| 显式按钮 | 太阳系工具栏新增 `−` / `＋`（`#solarZoomOut` / `#solarZoomIn`） |
| 键盘 | `+` / `=` 放大，`-` / `_` 缩小（原有方向键保留） |
| 只读诊断 | `SolarView.camera()` 返回 `{dist, target, fov}`，供测试确认缩放生效 |

验证（注入式浏览器）：`62.00 → 49.60 → 39.68`（连续放大），`39.68 → 49.60`（缩小）。

## 2. 行星真实感

### 2.1 新增 `core/planet-textures.js`

程序化等距贴图 + 正交球面采样 + Lambert 光照 + 临边辉光，离屏 canvas 生成后按
（天体 / 尺寸 / 光照方向 15° 档）缓存，上限 48 张。

各天体做法：

| 天体 | 表面特征 |
|---|---|
| 木星 | 纬向带 + 湍流 + 大红斑（南纬 22°）+ 极区混沌 |
| 土星 | 纬向带 + 极区涡旋（冷灰） |
| 火星 | 铁锈底色 + 暗区反照率 + 极冠 |
| 金星 | 硫酸云顶超旋转条带 + 极区暗化 |
| 水星 | 撞击坑灰阶 + 亮斑 |
| 天王星 | 淡青 + 弱纬向带 |
| 海王星 | 深蓝带纹 + 大暗斑 |
| 月球 | 月海 + 高地（星图中仍由 miniMoon 负责相位） |

### 2.2 渲染接入（`core/sky-renderer.js`）

- 半径 ≥ 5px 的**行星**直接使用球面贴图精灵（带光照与相位终结线）；
- 半径不足或模块缺失时，退回原来的渐变球 + 简化纹理 + 相位遮罩，保证降级可用；
- 太阳不套相位遮罩；月球保持既有 `miniMoon`。

### 2.3 土星环

- 由单根灰环改为 **C / B / 卡西尼缝 / A 四条环带**，每条透明度与宽度独立；
- 短轴仍按真实环倾角 B 计算（`ry/rx = |sin B|`），2026 年接近环面穿越时自然变细。

### 2.4 太阳系视图

- 精灵分辨率档位从 8px 一档改为 **4px 一档**（下限 32px），「全系」视图下小行星也能呈现带纹；
- 太阳系视图本身已有逐像素球面贴图 + 缓存，本次未重构其贴图算法。

## 4. 真实行星贴图（授权后追加）

### 4.1 数据源与许可

| 项 | 值 |
|---|---|
| 来源 | Solar System Scope — `https://www.solarsystemscope.com/textures/` |
| 许可 | **CC BY 4.0**（可商用，须署名） |
| 天体 | 太阳、水星、金星（大气层）、地球、火星、木星、土星、天王星、海王星、月球（10 个） |
| 原始 | 2K JPEG（0.2–1.0 MB/张），存放 `tools/fixtures/planet-raw/` |
| 打包 | 1024×512 JPEG q82 → Base64 → `data/planet-textures.js`（**846 KB**） |
| 署名 | 设置 → 数据与核验 新增「Solar System Scope · CC BY 4.0」条目 |

下载后逐张校验 JPEG 魔数（`FF D8`），构建脚本 `tools/build-planet-textures.py` **只读本地文件、不联网**，
输出头部的 `license / attribution / source` 字段可人工核对。

### 4.2 接入方式

- `PlanetTextures.init()` 启动解码，`sampleReal(key,u,v)` 做最近邻采样（u 环绕、v 夹紧）；
- **球面精灵**：`sphereSprite()` 优先采样真实贴图，未就绪时退回程序化表面；
- **太阳系视图**：`texturePixel()` 优先采样真实贴图，解码完成后 `SolarView.refreshTextures()` 作废烘焙缓存并重绘；
- 图像以 `data:` URL 加载，不污染画布（无需 `crossOrigin`），`file://` 与 standalone 均可用。

### 4.3 性能处理

| 问题 | 处理 |
|---|---|
| 单次 `getImageData(1024×512)` 约 2 MB，会阻塞主线程 | 按 **128 行分片**读取，片间 `setTimeout(0)` 让出时间片 |
| 10 张同时解码造成启动抖动 | 每张错开 30ms 启动 |
| 内存 | 10×1024×512×4 ≈ **20 MB**；桌面可接受，低端移动端需注意（已登记） |

### 4.4 顺带修掉的一个真实缺陷

回归时发现「拖动改变 yaw」连续失败：银河背景异步重建完成后，`SkyRender` 会用 `lastPaint` 里的**过期 vm**
重绘整幅画面，把用户刚拖动到的视角弹回旧位置，`_meta` 也随之错乱。

修复：新增 `SkyRender.setRepaintHook(fn)`，由 `app.js` 用**当前**相机参数重绘（全屏用 `drawViewerNow()`，
小图用 `refreshPanels()`），并加递归保护。修复后 `v2-sky-01-browser-test` 恢复 **21/21**。

## 5. 已知限制

| 编号 | 限制 |
|---|---|
| R-1 | 采用 Solar System Scope 2K 贴图（CC BY 4.0），非 NASA 公有领域；纹理方向/本初子午线以其官方约定为准 |

| R-4 | 太阳系视图与星图各自维护采样路径，共用同一份贴图数据但未合并渲染实现 |
| R-5 | 贴图解码常驻内存约 20 MB（10 × 1024×512×4），低端移动端需评估 |

## 6. 查看方式

刷新页面（建议 `Ctrl+Shift+R` 绕过缓存）：

1. 太阳系视图：工具栏 `−` / `＋`，或键盘 `-` / `+`，或滚轮 / 双指捏合；
2. 星空全图：点视场档位 `70°`，把火星/木星/土星移入视野，观察球面带纹、相位与环带。
