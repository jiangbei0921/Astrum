## 5. 科学证据质量

### Evidence 去重

- 同 DOI 多镜像 → 1 条；`duplicates` 记录。
- 无 DOI 论文：标题 + 年份 + 首作者 → 同标题不同 URI 去重。
- 不同 DOI → 独立来源。
- 同源多记录不按 URL 数量计为独立证据。

### Claim 分类

- FITS 定量 Claim：CalcRecord + `std/sqrt(n)` uncertainty；
- 论文摘要：qualitative、abstractOnly、partial/weak；
- 无支持 Claim：hypothesis/unknown，报告列入缺口；
- 报告为每条结论标注 `evidenceScope`（abstract-only / observation / calculated / catalog）。

### 冲突判断

- 同实体、同量纲分组；pc/ly、arcmin/deg 等换算后比较。
- 有不确定性：差异 > 1σ 合成不确定性 → `conflicts`。
- 缺不确定性：仅 `differences` + `insufficient_information`，不武断判冲突。
- 参考系/历元不同：`differences`，不判冲突。
- 不同量纲：不比较。
- `conflictsOf` 仍返回数组，新增 `compareClaims/differencesOf`，保持旧 API。

### 不确定性表达

- `std/sqrt(n)` 明确为样本均值标准误，不包装成完整科学不确定性。
- 报告 `limitations` 与 UI 局限区块说明摘要级、SIMBAD/FITS 缺失。

### 尚存局限

- 阈值按 1σ 简化；未按物理量配置不同显著性门槛。
- 未引入仪器误差/系统误差模型。
- 论文全文未获取。
