## 2. 实现细节

### 2.1 `core/planet-visuals.js`（1.0.0 → 1.1.0）

新增四个纯函数，全部只读 `Astro`：

```js
phaseAngle(key, jd)   // 余弦定理解相位角，返回度
illumFraction(iDeg)   // (1 + cos i) / 2
ringTilt(jd)          // 土星 B 角（J2000 极轴 RA 40.589° / Dec 83.537°）
diskTexture(key)      // 96×96 离屏纹理，按 key 缓存；无 document 返回 null
```

- `phaseAngle` 与 `Astro.planet()` 内部公式一致（`cosI = (r² + Δ² − R²) / (2rΔ)`），避免 `asin` 的锐角歧义；
- `ringTilt` 忽略极轴长期进动，属**示意级近似**，已在代码注释中标明；
- `diskTexture` 只做色带与简单特征（木星条带+大红斑、土星条带、火星极冠、金星云带），不是摄影贴图。

### 2.2 `core/sky-renderer.js`

- 新增 `nightOverlay(g, cx, cy, r, iDeg, ang)`：终结线投影为椭圆（半短轴 `r·|cos i|`），
  `i<90°` 向左收（凸相），`i>90°` 向右鼓（残月/新月），裁剪在球体内；
- `bodyLayer()`：
  - 土星环短轴由固定 `0.62r` 改为 `r·1.95·|sin B|`（下限 0.6px），环面穿越年份自然变成细线；
  - 半径 ≥ 7px 时贴程序化纹理（`globalAlpha = 0.62`），否则退回原有条带/极冠画法；
  - 仅 `kind !== 'sun'` 且 `r ≥ 3.5` 时绘制相位遮罩；月球仍由 `miniMoon` 负责，不重复。
