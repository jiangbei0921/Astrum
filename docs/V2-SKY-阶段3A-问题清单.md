| 级别 | 定义 | 典型示例（仅示例，不等于已存在） |

| P0 | 天球方向、坐标映射或科学正确性错误 | 银河整体 180° 反转；银心出现在相反方位；银河与恒星反向运动；经纬度为正负号导致镜像 |

## 4. 待观察项（不是缺陷，仅提示重点关注）

以下内容来自当前实现的**已知特性**，实机时需确认是否构成问题；在确认前不得计为缺陷。

| 编号 | 内容 | 背景 | 需要确认的点 |
|---|---|---|---|
| O-1 | 相机/视场变化必然重建 160×160 屏幕栅格 | `rasterKey` 含 yaw/pitch/fov/w/h，无相机级缓存复用 | 拖动时掉帧是否影响可用（P1 还是 P2） |
| O-2 | 最近邻采样（纹理→天空纹理→屏幕栅格） | P1-1 评估后保留，未升级 | 高 FOV 是否出现明显块状/阶梯 |
| O-3 | 512×256 纹理为细节上限 | 冻结约束，不扩分辨率 | 大视场模糊是否越过可接受阈值 |
| O-4 | 时间/地点变化有 150ms 去抖 | `THROTTLE_MS=150` | 快速改时间时是否出现「旧图停留」被误判为错误 |
| O-5 | 鱼眼圆盘外四角无银河 | `Rmax = min(W,H)*0.49`，圆盘外为透明 | 是否被误认为「银河缺失/断层」 |
| O-6 | 银心方位依赖 `atan2(vx,vy)` 与 `(az/2π)%1` | P0-1 修复点 | 在 90°/180°/270° 等边界方位是否出现 1 像素级接缝 |
| O-7 | 恒星光晕仅 `mag<=2.5 && alt>0` | P1-2 实现 | 低空亮星光晕是否过强/过弱 |
| O-8 | 无图层开关 UI | `SkyLayers` 仅内部实例 | 无法做背景开/关 A/B 对照（BLOCKED 项，不是缺陷） |
| O-9 | 桌面缩放下限 40° | `zoomViewer` 夹在 40–178 | 30° 视场不可测（BLOCKED 项，不是缺陷） |
| O-10 | `sky-background.js` 文件头注释写「192×192」 | 实现常量实为 160 | 文档/代码注释不一致（P3，已在交付报告登记） |
