## 2. P1：全场景统一入口

### 2.1 分流规则

```
AstroRequest.classify（一次 Router）
  ├─ L1/unknown → 旧链路
  └─ L2-L4 → AstroControlBridge.canControl
        ├─ 本地：无附件或全 FITS → Control
        ├─ Web/云端：route.mode === 'research' → Control
        ├─ 显式对比：local + 无附件 + forceCompare → Control（T-D）
        └─ 其它 → 旧链路
```

- Web/云端复杂研究已进入 Control；普通 L1/L2 非研究仍保留旧链路。
- 显式对比模式在 UI 中传入 `forceCompare`，Planner 生成 T-D；Control 回退时 Adapter 追加 `compare` section，逐目标展示 RA/Dec/alt/az，不覆盖其他目标。
- 缺目标数据时 `compare` section 不生成，绝不虚构缺失目标。
- Router 只执行一次；Control 复用 `routeData`。
- 云端来源的旧“云模型表述”不再调用；这是功能取舍，已登记 PARTIAL。

### 2.2 涉及文件

- `core/control-bridge.js`：`canControl` 扩展、`forceCompare/fulltext` 透传。
- `core/control.js`：`forceCompare` 传 Planner；全文参数注入；compare fallback。
- `core/request.js`、`core/app.js`：统一入口参数。
- `core/planner.js`：`forceCompare → T-D`。
- `core/compose-adapter.js`：`compareSectionOf`、compare fallback、全文 Evidence 收集。

## 3. P2：论文全文能力

### 3.1 新增模块

| 模块 | 职责 |
|---|---|
| `core/pdf-text.js` | 零依赖 PDF 解析：Flate 流、对象流、页面/内容流、文本抽取、章节、分块、页码 |
| `core/paper-fulltext.js` | PDF URL 解析、下载、大小/超时/取消、缓存、Evidence 构建 |
| `core/evidence.js` | 增加 `contentLevel`、全文/摘要键分离、arXiv/pdf URL |
| `core/claims.js` | 全文 Evidence 构建 Claim（仍保持保守支持强度） |
| `core/report.js` | 论文分组、全文/摘要统计、章节/页码、limitations |
| `core/research-ui.js` | 全文/摘要统计、论文全文标记与章节 |

### 3.2 全文流水线

```
paper.search → 公开 PDF URL（arXiv / OA pdf_url）
  → fetch（12 MB / 30 s / AbortSignal）
  → pdf-text（多 HDU 文本流 / 章节 / 页码未知则 null）
  → chunks（chunkId/paperId/section/page/doi/sourceUrl）
  → fulltext Evidence（contentLevel=fulltext）
  → Claims（保留 evidenceRefs）
  → Reducer → Report（paperStats/limitations）
  → Research UI（全文 vs 仅摘要）
```

- 无公开全文：保留元数据/摘要，`abstractOnly`、`fullTextUnavailable`、失败原因。
- 出版方 PDF 返回 HTML/反爬：`not_pdf`，清晰记录，不伪装成功。
- 不绕过付费墙/登录/版权；只使用公开可访问 PDF。
- 页码不可靠时写 `null`，不伪造。

### 3.3 真实结果

- `astro-ph/9901001`（公开 arXiv，185,574 B）：
  - 5 页；
  - 章节：正文 / ABSTRACT / INTRODUCTION / RESULTS / DISCUSSION；
  - 22 个正文分块；
  - 4 条 fulltext Evidence（上限 4）；
  - 报告 `paperStats.fulltext=1`，结论 `evidenceScope=fulltext`。
- Registry `paper.search + fulltext` 链路已实现；OpenAlex 首条常指向出版社 PDF，部分返回 HTML，已按失败记录，不冒充真实全文。
- 浏览器 CSP 已放行 `arxiv.org` / `export.arxiv.org`；PDF 端点 `access-control-allow-origin: *`。

### 3.4 资源保护

| 限制 | 默认 |
|---|---|
| PDF 大小 | 12 MB |
| 下载超时 | 30 s |
| 最大页面 | 40 |
| 最大正文字符 | 200,000 |
| 最大分块 | 40 |
| 单篇 Evidence 块 | 6（Control 4） |
| 每次尝试论文数 | 1（最多 3） |
| PDF 缓存 | 8 篇 LRU |
| 取消 | AbortSignal 贯穿下载；解析前检查 |

## 4. 科学证据与 UI

- `contentLevel`：metadata / abstract / fulltext / extracted_claim（当前实现 abstract/fulltext）。
- 同 DOI 摘要与全文不互相覆盖；独立来源仍按 DOI/sourceId 计 1。
- 全文结论 `evidenceScope=fulltext`；摘要结论 `abstract-only`；页码/章节保留。
- Report `paperStats`：searched / fulltext / abstractOnly / failed / fulltextEvidence / abstractEvidence。
- UI 概览显示“全文 x / 仅摘要 y”；论文条目标记全文/仅摘要、页数与章节；链接安全转义。
- 冲突判断：单位换算、1σ 合成不确定性、参考系/历元差异 → `differences`，不武断判冲突。
