数据与隐私

最后更新：2026-10-26 · 本文只描述当前代码的实际行为，不承诺未来功能。

一句话总结

ASTRUM 没有服务器，也不收集任何数据。你的设置与对话只存在你自己的浏览器里。除了你主动触发的联网查询，没有任何内容会离开这台设备。

存放位置

数据存在哪里谁能看到
设置、技能记录、观测计划你的浏览器 localStorage只有你
对话与消息你的浏览器 IndexedDB只有你
多档案数据同上，按档案分别存放只有你
API 密钥（如填写）你的浏览器 localStorage只有你
我们无法读取、备份或恢复你的任何数据——没有这个通道，代码里就不存在。

什么时候会有内容离开你的设备

只有以下三种情况，且都由你的操作触发：

操作发送内容接收方
点击答案下方的「SIMBAD」按钮天体名称（如 M42）simbad.u-strasbg.fr
使用联网检索来源检索关键词NASA / Wikipedia / OpenAlex / Semantic Scholar 等
填写自己的 API 密钥并选用云端模型对话内容OpenAI / Anthropic / DeepSeek 等对应厂商
关于云端模型：一旦选用，你发给 ASTRUM 的问题会作为请求发送给该厂商，并受其隐私政策约束。若不希望如此，请保持默认的本地来源（离线可用），不要配置密钥。

我们不做什么

  • 不做访问统计，不埋点，不写 cookie（本应用不使用任何第三方脚本）。
  • 不读取你的定位。天气类功能若将来启用，会改为手动选择城市，而非定位。
  • 不上传你的对话、设置或设备信息。
  • 不向第三方转售或共享任何数据——因为没有可转售的数据。

如何删除你的数据

  • 清空对话：设置 → 历史记录 → 清空当前对话 / 清空全部历史。
  • 清空技能记录：设置 → 我的器材 → 清空全部技能记录。
  • 删除某个档案：设置 → 档案 → 删除档案（会连同该档案的全部数据）。
  • 彻底清除：在浏览器设置中清除本站点的数据（Cookie 与站点数据）。

删除即不可恢复，因为不存在备份。

导出带走

设置 → 数据 → 导出全部数据，会生成一个 JSON 文件，包含设置、技能与全部对话。该文件保存在你的设备上，不经由任何服务器。导入时会作为一个新档案加入，不会覆盖现有数据。

安全边界

  • 数据安全取决于你设备与浏览器的安全，ASTRUM 无法提供超出此范围的保护。
  • 若在共用设备上使用，请为不同使用者建立不同档案；档案之间的数据互不可见。
  • API 密钥以明文形式存放于浏览器本地存储，请勿在公共设备上填写。

「每日前沿」列表

顶栏「前沿」里的论文与报道，是构建时由项目维护者从 arXiv、ESA、ScienceDaily 的公开接口抓取后随页面一起发布的，不是你的浏览器去请求的。因此：

  • 打开页面、展开「前沿」不会向任何外部服务器发送数据，也不会暴露你的 IP 与所在地。
  • 该列表的内容未经本项目核验，只作阅读入口，不参与答案推理；引用前请点开原文核对。
  • 点击条目会跳转到原站点（arxiv.org / esa.int 等），此后适用该站点的隐私政策。

变更
